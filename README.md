# Live Console

Live Console은 방송에 필요한 웹 화면과 보조 도구를 한곳에 모아
방송 중 여러 프로그램을 오가는 작업을 줄여주는 Windows용 운영 프로그램입니다.

## 주요 기능

- **방송 플랫폼**

  사용하는 플랫폼의 웹 스튜디오를 Live Console 안에서 열 수 있습니다.
  로그인 상태가 유지되므로 방송 관리 페이지에 빠르게 접근할 수 있습니다.

- **웹 오버레이**

  웹페이지 주소를 등록하고 원하는 위치에 배치하면
  다른 프로그램을 사용하는 동안에도 해당 화면을 계속 확인할 수 있습니다.

  1모니터 게임 방송에서는 채팅창을 게임 화면 위에 띄움으로써
  화면을 전환하지 않고 채팅을 확인할 수 있습니다.
  투명도와 클릭 무시를 설정하거나 여러 배치를 프리셋으로 저장할 수 있습니다.

- **배경음악**

  Live Console 안에서 YouTube 배경음악을 재생할 수 있습니다.
  가사 또는 스튜디오에서 노래를 시작하면 음악이 자동으로 멈추고,
  노래를 종료하면 이전에 듣던 음악이 다시 재생됩니다.

- **가사**

  가사를 한 줄, 두 줄 또는 세 줄 단위로 나눈 뒤
  이전·다음 버튼으로 표시할 부분을 직접 넘길 수 있습니다.
  작성한 가사는 저장해 다음 방송에서도 다시 사용할 수 있습니다.

- **스튜디오**

  Live Console 안에서 송스튜디오에 로그인하고 송스튜디오의 공연을 시작하면
  세트리스트를 불러와 TJ노래방 또는 YouTube 반주와 연결할 수 있습니다.
  곡의 시작·종료와 함께 반주, 준비된 가사와 배경음악을 제어합니다.

## 다운로드

[최신 릴리즈](https://github.com/GStar0325/LiveConsole-Releases/releases/latest)의
Assets에서 `LiveConsole-win-x64.exe`를 내려받아 실행해 주세요.

기존 버전은 프로그램의 `설정 > 업데이트 확인`에서 업데이트할 수 있습니다.
